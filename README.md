# WoT Replay Analyzer

**English** · [Deutsch](#deutsch)

Downloads for WoT Replay Analyzer, a Windows app for analyzing your **World of Tanks replays**. This repository only contains
releases. The source code is not public.

**[Download the latest version](https://github.com/doepkec/WoTReplayAnalyzer-Releases/releases/latest)**

## What it does
- Imports your replay folders and shows every battle in detail
- Replays battles on the minimap or on a 3D map
- Statistics with your own charts, and heatmaps of your battles on each map
- A 3D armor inspector with penetration view

The app is a **learning tool** for understanding the game's mechanics. It only analyzes finished replays and reads game files
offline. It does not touch the game client, reads nothing during a battle and shows nothing in the game.

## Getting started
1. Download `WoTReplayAnalyzer-<version>-win-x64.zip` from the release and unpack it.
2. Start `WoTReplayAnalyzer.exe`. .NET does not need to be installed.
3. Windows SmartScreen may warn about an "unknown publisher", because the file is not signed: "More info" → "Run anyway".

Names, images and models are read from your own WoT installation, so the app ships no game content. The interface is available in
English and German. Your data stays on your computer in `%LOCALAPPDATA%\WoTFileReader`.
